# 像素战斗特效与多幕大招制作手册

> 完整范本：`tools/warrior-viewer/prototypes/spear/effects-source.ts` 与 `export.ts`。

## 1. 双层混合架构（`normal` 底光 + `add` 炽核）

每套像素特效强制输出两张同尺寸帧条，以同一原点叠加播放：
- **`*-base.png`（`blend: 'normal'`）**：提供轮廓饱和度与对比基底，确保在**亮草地、浅灰底**上清晰可见；
- **`*-add.png`（`blend: 'add'`）**：叠加高亮内脊、火星与能量核心，确保在**暗色地牢与战斗混战**中通透耀眼。

核心绘制约定：
- **亮度优先覆盖（`plotMax`）**：维护色阶权重表 `COLOR_RANK`（`.`=0 → `d`=1 → `D`=2 → `B`=3 → `C`=4 → `L`=5 → `g`=6 → `W`=7），叠加弧光与火花时只允许更亮色阶覆盖暗色阶，避免后画的边缘糊掉主锋芯。
- **帧率与逻辑帧对齐**：固定 `EFFECT_FPS = 50 / 3`（每帧 `60ms`，与战斗逻辑帧 `LOGIC_FRAME_MS = 60` 一一对应），出光帧（`swing`）通常比命中帧（`strike`）早 **1 帧**，保证刀光刚扫到敌人时弹出伤害数字。
- **方向裁剪与镜像**：绘制 `west`、`south`、`north` 三向（或全向无方向 `default`），`east` 由导出器自动复制 `west` 并设 `mirrorX: true`。

## 2. 按招式定位分层的色板设计

不要让所有技能共用同一套颜色，按打击重量建立一眼可辨的色相层级：

| 招式定位 | 色板风格 | 关键视觉特征 |
|---|---|---|
| 普攻三段 | 素银（`SILVER_*`） | 轻灵克制、低饱和冷白灰，不抢主动技能风头 |
| 常规突刺/贯气 | 蓝青（`BEAM_*`） | 锐利柳叶锋芯 + 青蓝气尾 |
| 破甲重刺 | 赤金/炽白（`HEAVY_*`） | 高温烈焰边 + 炽白核心 + 向后喷射破甲气锥 |
| 重劈震地 | 暗金/土黄（`SLAM_*`） | 厚重琥珀金弧 + 地面椭圆震裂冲击环 + 碎岩金星 |
| 狂风横扫 / 连刺 | 冰青 + 软饰流红（`GALE_*` / `FLURRY_*` / `SPIN_*`） | 冷钢青白刃弧穿插 1~2 股高饱和软饰流光 |
| 满怒多幕大招 | 圣金 + 亮蓝冰青（`SOVEREIGN_*`） | 双股螺旋主气束 + 层叠音爆环 + 月牙破空前锋 |

### 半透明护体能量罩「零黑框」专项规范

当特效是大面积半透明柔光罩（如扣地半球护罩 `spear-sovereign-dome`）时，**绝对不能直接沿用常规刀光的深蓝低亮暗边色板**——否则在 `#777c79` 浅灰底和亮色地面上，`normal` 层的深蓝像素会压暗背景，变成难看的「塑料粗黑框」：
- **`base` 层只放高亮低透柔光色**：`R >= 160`、`G >= 220`、不透明度 `A <= 90`；
- **3D 扣地半球拆前后双层**：
  - `*-dome-back`（`placement: 'ground'`）：画人物脚后侧贴地椭圆封边与背面螺旋上升气流；
  - `*-dome`（`placement: 'above-characters'`）：画 `Z >= 0` 高拱穹顶、90° 垂直落地边、脚前高亮接地封边与正面螺旋上升气流，彻底消除悬浮肥皂泡感；
- **平滑收尾不内缩**：末尾 2 帧保持完整原大尺寸（外宽差 `<= 3px`）逐步降透明度原地渐隐，不做向内坍缩成小圆环。

## 3. 六大典型特效几何构造方法

1. **方向线性刺芒与贯通波**：沿局部主轴参数化绘制（前锐锋尖 + 渐变气脊 + 尾散火星），西向水平铺展，南/北向按俯视比例做纵深缩短，确保与对应方向枪尖/刀尖重叠。
2. **四正方向对称横扫弧光**：
   - 弧中心按人物腰胸原点偏移（约 `y = -12`），**南向对称于 `+90°`、西向对称于 `±180°`、北向对称于 `-90°`、东向镜像对称于 `0°`**；
   - 峰值帧像素质心方位角偏差必须 `<= 4°~5°`，避免弧光歪斜偏一侧。
3. **南北向窄 J 形 3D 透视上挑立弧**：
   - 纵向跨度饱满（`>= 48px`）由下而上抽拔，水平延展收束在肩宽内（`maxLx <= 20px` 且弧宽 `>= 8px`），既有 3D 立体弯度又不遮挡角色正面。
4. **真 3D 俯视投影旋转特效**：
   - 定义 3D 俯视投影 `project3D(x, y, z)`，按深度 `depth` 动态调制笔触粗细与色阶（近粗亮、远细暗），可做出左右双侧立体舞花（`/ 🧍 \`）或 360° 俯视椭圆刃环 + 切向破风丝。
5. **多幕复合大招编排范式（以 28 帧「万圣龙王破」为例）**：
   - **第一幕（F0..F11）护体蓄势**：前后双层扣地半球罩持续旋转，F3/F6/F9 配合轻触火花脉冲；**人物全程保持原色，不挂变色 `appearanceColors`**；
   - **第二幕（F12..F15）顿帧凝核**：极简十字星芒闪光提示爆发，不叠杂乱收缩圈；
   - **第三幕（F16..F25）四向全屏十字齐发**：单帧通过显式 `variant: 'north' | 'west' | 'east' | 'south'` 同时派发四路全屏冲击波（东西单臂 `>= 320px` 跨全屏 660px，南北单臂 `>= 220px` 跨全屏 476px），其中 **`north` 走 `placement: 'ground'` 压在角色背后不挡头脸**，其余三向走 `above-characters`。
6. **特效装箱与 WebGL 安全上限**：
   - 样板导出 `export.ts` 必须采用**按高度降序的货架式矩形装箱**，限制单行最大宽 `MAX_SHEET_WIDTH = 3840`，保证总宽与总高严格 `<= 4096px`（防止低端机/移动端 WebGL 报纹理越界黑块）；
   - 正式图集由 `npm run atlas:all` 自动裁透明边分块装箱成无损 WebP。

## 4. 打击节奏与克制震屏

- **帧同步**：动作帧 `cycleFrames` 必须完整覆盖最后一帧收招；出光帧在挥击起手点，命中帧紧随其后 1 帧。
- **震屏预算**：强制震屏（`shake: true`）是稀缺冲击资源，滥用会导致连招晕屏。**全职业仅在 1–2 个重磅砸地控制技或终极必杀的主爆发帧保留强制震屏**（如龙枪全 9 主动技仅留「伏龙震 F4」与「万圣龙王破 F17」共 2 次）；普攻、连刺、常规横扫、旋风与大招次段均不震屏。
- **画布背景提醒**：在 `warrior-viewer` 预览 `add`/`screen` 特效时，底色必须由 Phaser 内部不透明绘制（`transparent: false`），否则透明帧缓冲会把纯黑底加色帧渲染成黑方块（已由工作台固化）。
