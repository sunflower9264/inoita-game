# 纸娃娃人物装配、武器切片与四向身法手册

> 完整范本：`tools/warrior-viewer/prototypes/spear/source.ts` 与 `export.ts`。

## 1. 武器像素切片规范

### 1.1 14 色量化色板（与原版明暗口径一致）

用单字符 ASCII 网格绘制，再经色板映射输出透明 PNG（改一款换皮武器只需换一份色板，切片与全部动作零改动）：

| 角色 | 字符 | 参考色（基础铁枪） | 用途 |
|---|---|---|---|
| 透明 | `.` | `[0, 0, 0, 0]` | 背景 |
| 外轮廓 | `K` / `D` | `#180c08` / `#312429` | 杆/饰 1px 暖黑外边（`K`）、金属刃 1px 暗钢边（`D`） |
| 金属 4 阶 | `S` / `M` / `L` / `H` | `#525d6b` → `#eef4f8` | 暗面 / 中调 / 亮面 / 锋脊高光 |
| 握柄 3 阶 | `w` / `W` / `u` | `#3b251e` → `#9b6e4a` | 暗边 / 中调 / 上缘受光边 |
| 金属箍 2 阶 | `g` / `G` | `#8c6228` / `#dfb454` | 暗面 / 亮面 |
| 软饰/缨 3 阶 | `r` / `R` / `P` | `#6b1414` → `#f2624e` | 暗红 / 正红 / 高光丝 |

绘制顺序：**主杆 → 尾镦 →（若刃在镜头前，先画背侧软饰）→ 刃面（中脊 `H`、上亮下暗）→ 吞口箍 → 软饰 → 1px 四邻外轮廓（金属用 `D`，其余用 `K`）**。

### 1.2 尺寸统一、透视缩短与正向顶光

- **同平面统一标准长度**：所有东西向、斜向、立持、背负、舞花切片的最大像素跨度必须收口在同一区间（长枪为 `50.0..53.0px`），杜绝部分招式突然拉长或变短产生“橡皮筋感”。
- **南北纵深透视缩短**：南向/北向平提与直刺沿镜头纵深方向，适当压缩长度（长枪约 `37..43px`）体现 2.5D 俯视近大远小。
- **严禁 `scaleY: -1` 翻转武器**：垂直翻转会倒置金属上缘受光边与下垂软饰重力。需要镜像倾角（如舞花左上斜与左下斜）时单独出一张正向顶光切片。
- **东向零重绘**：西向制作完成后，东向整条姿态设 `mirrorX: true` 直接复用西向帧表（渲染时水平镜像），既省工又天然保证对称。
- **软饰微摆帧**：待机/行走/背负每种角度出 `sway: 0` 与 `sway: 1` 两张切片，配合 `swayPeriod`（待机 `7` 帧、行走 `2` 帧）产生灵动呼吸感。

## 2. 全换装兼容的身体骨骼三件套

原版衣柜有 **63 套上衣（`coat-front`）、62 套下装（`coat-back`）、70 款头饰（`head-front`/`head-back`）、11 款角色脸型（`body`）与 4 款披风（`cloak`）**。动作帧只引用以下全量共有切片，就能在所有换装和佣兵外观下 100% 干净渲染。

### 2.1 手臂预设（`armsPreset`）

- **合法切片池**：`coat-front` 索引 `[5..14]`（63 套上衣 100% 共有）；`angle` 必须恒为 `0`（支持原版标准 `scaleY: -1` 上举臂）。
- **禁用雷区**：
  - `coat-front[15]`：刺客猫背胸甲，不要混入战士/武者系站姿；
  - `angle !== 0` 的旋转手臂：容易脱肩成怪手；
  - `coat-front[5]` 且 `y < -30`：短剑遗留的头顶悬空手。
- **躯干跟随**：手臂坐标相对躯干基准 `baseTorsoX` 声明（西向默认 `-1`，南/北向为 `0`），导出时自动叠加 `torso.x - baseTorsoX` 与 `torso.y`，躯干呼吸/前倾时双手自动贴肩不脱臼。
- **三层遮挡位（`layer`）**：
  - `behind-torso`：远侧手（躯干后面）；
  - `behind-weapon`：武器后方辅助手；
  - `front-of-weapon`：近侧实握主手（压在武器表面）。

### 2.2 下盘预设（`legsPreset`）

- 西/东向全部非行走战斗招式使用 `coat-back` 的 3 张全掌贴地战斗腿（统一接地底边 `botY = 4`）：
  - `ready`：`{ piece: 6, x: 0, y: -1 }` — 挺拔战姿（起势 / 蓄势 / 收势）
  - `bow`：`{ piece: 11, x: 0, y: 1 }` — 实踩宽弓步（直刺 / 连击 / 大横扫爆发）
  - `planted`：`{ piece: 18, x: 1, y: 1 }` — 沉马稳桩（舞花 / 重劈 / 上挑 / 蓄力）
- **铁律**：除 `walk-*` / `town-walk-*` 外，**严禁混入走路循环腿 `coat-back[7, 8, 9, 10]`**，防止出招时人物脚下原地踏步。

### 2.3 头部、上身与披风联动（`headPose`）

`HEAD_VIEW_PIECES` 严格保证脸、颈、发型/头盔成组切换不错位：

| `view` | `body` 脸 (`<4`) | `body` 颈 (`>=4`) | `head-front` / `head-back` | 用途 |
|---|---|---|---|---|
| `south` | `0` | `4` | `0` | 南向正视抬头 |
| `west` | `1` | `5` | `1` | 西/东向正视 |
| `turn-back` | `2` | `6` | `2` | 360° 旋风过渡背侧转头 |
| `north` | `3` | `7` | `3` | 北向背身 |
| `south-action` | `0` | `4` | `4` | 南向压眉发力（仅爆发帧，蓄势/舞花勿用） |
| `west-action` | `1` | `5` | `5` | 西/东向压眉猛刺/重砸 |

- **披风切片分段**：南向 `0..3`、西/东向 `4..7`、北向 `8..11`，通过 `cloakPiece` 随蓄力→爆发→收招逐帧飘动；默认跟随 `torsoDx / torsoDy`。
- **头部克制铁律**（除 360° 旋风类技能外）：
  - 只在当前朝向内做位移与微压眉，**不转向、不镜像**（`scaleX === 1`）；
  - 南向与北向全程锁定 `head.x === 0` 零横晃；
  - 整段动作水平与纵向位移方向反转 `<= 2` 次（多段连刺 `<= 3` 次），杜绝逐帧啄木鸟抖头；
  - 盘枪/蓄势/横扫南向保持 `head-front[0]` 平视抬头，不要切入低头埋胸切片。

## 3. 遮挡层序表（`insertMode`）

| `insertMode` | 插入位置与效果 | 典型用途 |
|---|---|---|
| `armsPreset` + 默认 | `backList → behindTorso → torso → behindWeapon → 武器 → frontWeapon → afterList` | 西/东向与南向腰胸高度双手战斗招式 |
| `armsPreset` + `back` | `behindTorso → 武器 → behindWeapon → backList → torso → frontWeapon → afterList` | 北向战斗招式、南向过顶蓄势（武器在身背后） |
| `armsPreset` + `front` | `...afterList → 武器 → frontWeapon` | 南向贴镜头前景横扫、上挑 |
| `back` | 整帧最底层 | 南/西/东向脱战斜背武器 |
| `on-back-north` | 披风/躯干之后、`body`/`head-*` 之前 | 北向脱战背负：压在披风表面，但不横切后脑勺头发/头盔 |
| `single-hand-west` | `farEmptyArm → torso → 武器 → nearGripArm` | 西/东向单手黄金重心平提，远侧空手在躯干后自然摆臂零穿模 |
| `before-right-arm-south` | 南向胸甲与握枪右臂（`scaleX=-1`）之前 | 南向单手提持，右手压杆、后段配重自然收在肩后 |
| `before-right-arm-north` | 升级北向握枪右臂（`piece:7`）并把武器插在右臂与披风之前 | 北向单手提持，铁镦偏右脚外侧 `x>=5` 零漏裆部 |
| `between-west-arms` / `between-south-arms` | 对应主副手臂切片之间 | 未用 `armsPreset` 时的轻量插层 |

## 4. 握持解剖分区与四向招式编排

### 4.1 持械解剖规律（以长杆武器为例，其他长兵器同理）

将武器从柄尾（`0%`）到锋尖（`100%`）分段：
- **日常待机 / 行走（单手平提）**：单手实握 `42%..53%` 黄金重心区，握手法向距离 `<= 2.0px`，另一只空手自然垂摆且距杆 `>= 3.0px`（防穿模或变成双手抱杆）。
- **脱战城镇（斜背）**：使用原版徒手城镇骨架 `pose-3980..3982`（待机）与 `pose-3983..3985`（行走），武器斜跨背后随步伐起伏。
- **战斗招式（双手发力）**：
  - 突刺蓄势（收把）→ 爆发（锁根滑把）顺杆前送放长距离；
  - 横扫 / 上挑 / 纵劈用宽矩杠杆把；
  - 突刺与立持聚气全帧双拳严格落在 `0%..55%` 纯握杆区（严禁摸到锋刃或红缨）；
  - 南向双拳沿武器轴向拉开 `>= 10%` 距离（杜绝叠拳成一团）。

### 4.2 常用原版基础身体骨架速查

| 用途 | 南向 | 西向（东向镜像） | 北向 |
|---|---|---|---|
| 城镇徒手待机 / 行走 | `pose-3980` / `pose-3983` | `pose-3981` / `pose-3984` | `pose-3982` / `pose-3985` |
| 单手持械待机 / 行走 | `pose-3986` / `pose-3989` | `pose-3987` / `pose-3990` | `pose-3988` / `pose-3991` |
| 战斗稳立基准帧 | `pose-4067` | `pose-4068` | `pose-4069` |
| 突刺发力参考骨架 | `pose-4061` | `pose-4068` + `legsPreset:'bow'` | `pose-4063` / `pose-4075[4]` |
| 过顶下劈骨架 | `pose-4076` | `pose-4077` | `pose-4078` |
| 360° 旋风骨架 | `pose-4094`（配 `mirrorBaseFrame` 与 `bodyDx` 归中） | 同左 | 同左 |

### 4.3 典型招式四向编排要点

- **基础与重刺**：F0 战姿 → F1..F2 后引收把（躯干微退 `torsoDx:+1`）→ F3..F4 爆发贯刺（`legsPreset:'bow'`、`west-action`/`south-action`、披风后扬）→ 后摇顺势收回。北向刺击保持右肋高位（`x >= 6, y <= -12`），双腿裆部零漏把。
- **180° 大横扫（西/东向）**：起势放 `back` 层北侧高蓄 → 经北西 → 正西最大伸展（`legsPreset:'bow'`）→ 南西 → 南南西（`legsPreset:'planted'`）扫出饱满 180° 弧幅（枪尖北 `<= -32px` 至南 `>= +18px`，总纵向跨度 `>= 55px`）。
- **普攻三段上挑（南/北向）**：忌用 0° 纯竖棍挡脸，也忌飘成 45° 侧砍；采用 ~19° 窄透视下探切片 → ~32° 过渡 → ~19° 陡角冲顶，双手像素全程贴杆 `<= 4px`。
- **原地零位移大招**：直接锁定稳立骨架 `pose-4067/4068/4069`（不动 `coat-back` 位置，或通过 `bodyDx/bodyDy` 抵消位移），确保全帧脚心漂移 `<= 3.5px`。
- **23 帧阵亡**：沿用原版 `sharedPoses.die-*` 节奏，西/北共用南向倒地、东向 `mirrorX: true` 镜像。
