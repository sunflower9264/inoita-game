# 物品掉落机制

怪物、地图宝箱、可破坏景物和古剑的掉落由 `public/content/drops.json` 配置，`src/domain/drops.ts` 按来源等级抽取。`src/domain/combat-rewards.ts` 结算击杀奖励，`src/domain/loot-pity.ts` 保存保底进度。

## 装备等级

怪物使用战斗中实际显示的等级。地图宝箱使用地图的 `chestLevel`，缺省时使用 `lootLevel`。景物和古剑使用 `lootLevel`。装备等级上限为 105，候选的穿戴等级在来源等级减 15 到来源等级之间，最低为 1；最近 5 级的候选权重为其他候选的 3 倍。

普通装备先抽武器、防具或饰品，在该类没有符合等级的物品时改从其他类别抽。黄装和紫装使用各自的装备池，并遵守同一范围。固定掉落按敌人配置直接发放，不受上面的装备等级范围限制。

低等级怪物保持自己的掉落等级。越级打败高等级怪物可以获得高等级装备。剧情人物专用装备和普通保留道具继续从普通掉落池中过滤；被封印技能书是例外，见下文。

## 奖励来源

| 来源 | 基础装备概率 | 说明 |
|---|---:|---|
| 普通怪 | 12% | 有独立的黄装和紫装机会 |
| 精英 | 50% | 推进黄装和紫装保底 |
| Boss | 100% | 普通装备最低为稀有品质，保底进度记 2 点 |
| 普通宝箱 | 20% | 箱子使用自身等级 |
| 优良宝箱 | 75% | 普通装备最低为精良品质 |
| Boss 宝箱 | 100% | 普通装备最低为稀有品质 |
| 灌木、坛子、木箱 | 各自配置 | 主要产出材料；幸运木箱的装备概率为 75% |

装备、黄装和紫装可各自判定，最终保留品质最高的一件。金币、材料和消耗品按各自槽位抽取。全队一次击杀只保留一份常规装备，其他队员仍各自结算金币和消耗品。任务掉落每次击杀全队结算一次。宝箱怪与景物埋伏怪击败后按自己的怪物等级结算。

`paidDropEligible` 标记的小首领按精英推进保底并参与保留道具掉落。守护泉水的牛头怪和深渊的恶灵也按精英结算，供高等级玩家重复挑战。

## 保底与首杀

保底全队共用。怪物等级不低于主角等级减 10 且装备池有合适候选时，精英击杀记 1 点，Boss 击杀记 2 点。普通怪有自然掉落机会，不增加黄装或紫装保底。

- 黄装连续 25 点未出时必中黄装或更高品质。
- 紫装连续 40 点未出时必中紫装，紫装池有符合来源等级的候选时累计。
- 黄装清空黄装进度。紫装清空黄装和紫装进度。装备进度按装备命中清零。
- 宝箱按类型单独记录装备保底，不累计怪物的黄装和紫装保底。
- 每种 Boss 首杀有保障。一次性剧情精英同样有首杀保障；有符合等级的固定装备时优先选取固定装备，其余情况优先给同档黄装，黄装池无候选时给稀有装备。首杀记录按敌人 ID 保存在存档。

旧存档升级时，逐项取各成员保底进度的最大值，写入全队进度；保留已有首杀记录和宝箱进度。

## 保留道具与封印盒

原版付费道具由 `reservedDrops` 独立配置。精英、Boss 和标记的小首领每次全队结算一次。直接装备与装备礼盒按怪物实际等级检查内容的穿戴等级，其他道具按主角等级筛选；一次性解锁道具保留领取记录。

被封印技能书也保留在 `reservedDrops` 表里，但不再限制领取次数：精英、Boss 和小首领的额外掉落、普通与高级怪的杂项池、黑点奸商和神灯商人的随机进货都能出。打开后从本职业全部技能里随机绑定一门，变成技能解锁书；解锁书使用后不消失，同职业佣兵未学会该技能时可以从 1 级解锁，已学会的佣兵不能使用，之后可用普通技能书继续升级。

掉落的封印装备盒保存来源等级，开盒时从盒内符合该等级范围的装备中抽取。没有符合条件的内容时，该盒子不参与本次掉落。已有旧盒子及剧情直接发放的盒子没有来源等级，仍按盒子原有内容抽取。

药水、强化卷按来源等级选择档位。普通镶嵌宝石按 1、20、40、60 级换档。通用材料保留各自掉落池。古剑只产出符合所在地图等级范围的武器。

## 验证

`tests/loot-redesign.test.ts` 覆盖怪物等级、共享保底和封印盒。相关用例还包括 `drops.test.ts`、`drops-pity.test.ts`、`drops-epic.test.ts`、`combat-rewards.test.ts`、`chests.test.ts`、`reserved-drop-system.test.ts` 和 `saved-game.test.ts`。内容或地图等级改动后运行 `npm run validate:content`，地图改动后更新 GM 剧情现场表。
