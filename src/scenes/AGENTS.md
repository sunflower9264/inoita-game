# src/scenes

Phaser 场景层：驱动生命周期、转发输入，把 domain、rendering、ui 的能力接起来。游戏规则不属于这里。

## 文件

- `world-scene.ts`：主世界，负责地图加载、角色移动、镜头与地图内交互。
- `world-combat.ts`：世界内战斗的装配与更新，把战斗规则接到场景表现。
- 队员离队时清空队伍同步签名，确保暂停期间重新上阵也会重建角色和控制器。
- 地图敌人的返回点取生成点并校正可站位置，读档恢复当前位置时保持返回点不变。
- `story-stage-scene.ts`：剧情舞台，承接对白、选项和演出期间的输入锁定。
- `menu-scene.ts`：标题与主菜单，含存档槽、云存档账号/改密页、更新日志与覆盖确认。
- `story-class-scene.ts`：新游戏的职业选择与角色预览。
- `formal-ui-scene.ts`：正式 UI 场景，承载 HUD、背包装备、商店等菜单面板。
- `audio-scene.ts`：音频设置页；跨场景常驻，切换场景不打断播放。
- `controls-scene.ts`：操作设置页，键位与控件布局。

- 出口预载随玩家移动方向切换目标，切换时取消旧目标请求；失败后同一目标延迟一秒重试，场景关闭释放迟到结果。

## 规则

- 剧情舞台恢复敌人时优先使用剧情外观；快照没有外观时按敌人 ID 从战斗目录恢复。
- 玩家存档的世界快照只保留敌人身份和现场状态；运行时剧情与回滚快照保留完整敌人外观。

- 地狱火等散布特效的视野尺寸用镜头宽高除以各轴缩放，交给战斗层的单位是地图像素；画面精度变化只改变采样，不改变散布范围。

- 主角进图、预取、换装和剧情装备投影共用「基础动作 + 已学技能」的外观范围；新技能必须等对应外观准备完成后才标记可用。换装后记录已投影装备，避免会话刷新重复准备；外观没变时保留角色动画与碰撞体，只有外观或主副手变化才更新攻击动作。技能素材清单只随职业、动作身份、已学技能和主副手物品变化，饰品数值仍由背包修订号正常刷新。

- `WorldCombat` 把地图的 `captureStandability` 接给敌人和佣兵的寻路器。一次搜索共用一份占位，走动时再由 `movement.canStand` 检查下一步。
- `WorldCombat` 还持有一份 `FlowFieldStore`，敌人端口按目标、目标所在 16 像素格和身体尺寸请求共享流场。流场只用 `terrainFree` 和 `blockedByContent`，不把会移动的角色当永久墙；每渲染帧和 `pathBudget` 一起重置。
- **补位落点避开主角和所有队友。** `partyLanding` 的侧位用 `Party.followSlotOf(leaderId, id)`，避让名单同时包含当前队长、主角和其余队友；操控佣兵时主角不属于 `allies`，必须单独加入，否则卡住补位会瞬移到主角身上。

- 场景只驱动生命周期、转发输入、调度下层模块；判定和数值规则写进 `src/domain/`，世界绘制交给 `src/rendering/`，屏幕界面绘制与输入交给 `src/ui/dom/`。
- **场景构造函数只保存依赖。** 场景由 `main.ts` 用 `new Scene(app)` 直接构造，这时 Phaser 还没把 `events`、`scale`、`add` 等系统注入到实例上；事件监听、销毁回调、尺寸监听都写进 `create()`，需要幂等时加一个 `xxxBound` 标记。
- 标题、职业选择、对白、选项、加载与阵亡界面使用 DOM 菜单表面；透明热区、文字与显示节点共用画框内的 CSS 坐标。剧情对白的点击推进挂在铺满画框的挡板上，整个屏幕都能补完打字机或翻到下一句；选项和「跳过」按钮层级更高，优先命中。立绘预载状态查 DOM 图片缓存，预载请求沿用页面取消信号。
- 对白翻页时沿用前文的颜色和颜色锁定状态，逐字进度仍按原文的位置计算。
- 职业选择的背景与待机角色留在游戏画布，菜单先按屏幕排版，再通过 `screenRectToCanvas` 将矩形交给 Phaser；背景与角色随画布采样精度换算，DOM 页面大小保持一致。职业切换只更新角色、选中标记和文字，按钮及背景保持原样。
- 对白与选项文字位于遮罩和底图之上；加载、暂停、竖屏或其他遮挡出现时同步隐藏，恢复后重新显示。
- 标题云存档页将按钮文字转到 DOM 文字层时，单参数的文字锚点同时用于横向和纵向，保持文字与按钮居中对齐。
- **标题页更新日志按需加载、按可视区渲染。** 主菜单启动不请求 `content/changelog.json`；点「更新日志」才加载，关闭后释放请求缓存。弹窗和环境设置页共用标题页的 `slot` 图框（金线贴面板外沿、内部半透明），不要再叠游戏内菜单的 24 像素边框和不透明黑底，否则标题背景上会多出一圈黑边；更新日志弹层使用标题页的完整宽度；主菜单文字放在遮罩和弹层后方，与按钮一起压暗；左侧版本列表和右侧正文独立滚动，切换版本只更新选中状态和正文，保留主菜单、弹层及滚动区；文字按所属滚动区的位置移动；默认选择内容中最新版本；右侧标题显示选中版本，条目前带序号；正文只输出滚动窗口内（含一层缓冲）的条目，滚动时重算窗口，不重建整份日志。加载方法必须作为 `this.app` 的对象方法调用，解构会丢 `this`。
- 标题页全屏状态变化时只更新设置项文字，保留设置页面和滚动位置；确认框和存档改名保留底层页面，改名后只更新对应存档名称。离开存档页或关闭场景后忽略迟到的改名结果。
- 标题页当前展示 `v1.0.7`，更新说明由 `public/content/changelog.json` 按游戏版本从新到旧维护；网页与 Android 热更新共用该版本展示。
- **确认框 DOM 文字直接取弹层的屏幕坐标。** `centerModal` 已经把弹层按页面变换放好；`modalTextPoint` 用弹层根节点的世界变换换算后就是画框 CSS 坐标，不能再减页面原点或除以页面缩放，否则文字会和横带、按钮整体错位。
- 世界小地图由 `StoryMinimap` 连接 DOM 组件和场景显隐；地图关闭时释放组件，地形与图标通过 DOM 资源预载准备。
- 小地图旁的帧率显示同时给出两个数：`rAF` 是浏览器 requestAnimationFrame 的每秒调用次数，`实际` 是游戏场景每秒真正交付的帧数。两者分开统计，每秒更新一次；限帧后 rAF 仍可能按屏幕刷新率跑，实际帧数才是玩家看到的画面节奏。
- 玩家主动释放的对敌技能完成后，由当前操控角色接普攻；技能被取消、施放失败或切到其他角色时不触发。
- 击杀奖励结算、召唤生命周期和交互决策在 `src/domain/`：场景只收集输入、播放表现、决定落点并执行 domain 返回的动作/奖励清单。
- `WorldScene.interact()` 把附近目标、任务槽和商店状态交给 `domain/interaction.ts` 的 `resolveInteraction`；选目标的 `updateInteractionTarget` 先按距离挑最近的一个，距离相同时再比交互档位：推进任务目标或待交付为 0，头顶有任务标记为 1，普通可交互对象为 2。任务 NPC 不能因为同格普通 NPC 排在人物数组前面而失去交互。交互前场景把角色转向目标，朝向不参与能否交互的判定。
- 有商店的 NPC 无论有没有招呼语，都算可交互目标；交互优先级仍由 `resolveInteraction` 决定。
- 掉落落点用 `lootLanding` 避开地图进出口；不要把物品图标落在门洞上。
- 舞台 `CREATE` 完成时始终交付 `onReady` 生命周期通知；启动过程抛错或在就绪前关闭时交付 `onError`，等待者不会悬空。等待画面的请求可独立取消，补画和收尾复用同一次启动。舞台衣柜准备接收画面取消信号，共用合成只在最后一个请求取消后中止。
- 世界与舞台的 `Wardrobe` 使用 `StoryContext.outfits` 共用合成外观，并按对应成员已学技能选择动作；场景关闭只释放自己的使用权，跨图不重复生成同一套动作。
- 剧情舞台只先准备待机、行走与恢复快照中的当前动作；`prepareClipAssets` 和 `prepareEffectAssets` 在实际动作前取得资源，重复动作复用本舞台持有的清单，取消或换幕只释放对应旧请求。
- 剧情舞台的地图与按需素材加载共用画面的取消信号，跳过时让出共享纹理队列。
- **伙伴基础动作常驻（标题页先预载，进图快速复用），技能动作按使用者加载。** 队伍面板预览只准备 `idle-south`，招募确认后调用 `preparePartyMember(...,{full:true,pin:true})` 预拼整套并 pin（最多两套），上阵/进战斗直接复用。技能动作和特效按成员已学技能装载，学新技能后由 `scheduleSkillAssetRefresh` 补，并在素材就绪后重拼整套外观。
- **常驻包先在标题页后台预载，进图继续补齐。** 标题页按小批加载全部职业和伙伴的基础动作与公共反馈；进图时 `buildEntryPlan` 只并入当前主角与已拥有成员职业的完整动作、已学技能特效和召唤物。`WorldScene.open` 仍等本次进图计划加载完再挂会话租约，失败留在加载页重试，不把常驻加载塞进游戏循环。
- 正式界面场景为背包和队伍装备页创建待机角色，复用当前衣柜外观并跟随菜单位置。
- **地图内学会新技能后要补素材。** 进图和开战的素材计划只覆盖当时已学的技能；玩家或伙伴升级、学新技能、换武器后，`WorldCombat` 用 `scheduleSkillAssetRefresh` 按签名补载新增技能的特效、姿态和召唤物。先用 `playerSkillGateNow`/`allySkillGateNow` 只比版本号，签名变化时登记完整资源清单，加载器只下载缺失项；新清单取得使用权后替换旧清单，迟到的旧签名直接释放，伙伴离队和关闭地图时释放。失败按 owner 退避（1s→30s，最多 5 次）；退队清除失败记录，迟到失败重验成员身份和签名。首次入队的两次异步准备都校验装备签名，变化后延后重试；血之渴望等自动反应也须等对应技能资源就绪。读档先等待当前队伍的完整技能资源，准备失败或队伍变化时在改写战斗现场前抛错，由调用者恢复原局。
- **每帧读取的技能数据按版本复用。** `partyPassives`、`partySkillsFor`、`equipmentRecovery`、`combatProcs` 用技能版本、背包修订、生命阈值、潜行和组队光环版本缓存；命中被动缓存时不重新整理装备，`syncAiSkills` 的蓝耗也按同样的版本键缓存，每逻辑帧只按当前法力更新频率；临时蓝耗属性或按时间增长的蓝耗修正存在时不缓存，改走实时计算。新增会影响这些结果的输入时，同步加进缓存键并在读档/成员移除时清空。
- **一次结算里同类命中反馈只响一次。** `showHit` 记下「帧号 + 出手者 + 结果种类」：范围技能一发打中多个目标时，暴击、格挡、命中、未命中各响一声，不随目标数量叠加；挥击声和持续伤害提示也按出手者每帧一次。
- **命中反应复用技能定义。** `reactionSkills` 按成员配置身份和版本、职业、成长类型、内容目录与已准备技能集合复用等级和反应描述；素材集合替换立即刷新。概率、当前血量、潜行及命中结果仍在原事件顺序实时读取，子增益等级保持在概率通过后查询。成员离场与场景关闭清理缓存。
- **地图触发用索引。** 进图和剧情投影后调用 `rebuildTriggerIndex`；`afterMovement` 只遍历本图的 region/near 候选，条件仍在判定时实时求值。近身事件逐个检查同类角色的距离。新增会改变地图身份或角色集合的路径要重建索引。
- **整图刷新和交互目标按变化复用。** `refreshStateSignature` 覆盖地图、控制者、`charactersRevision` 和任务等修订号；角色集合或角色身份变化时推进 `charactersRevision`，不逐角色拼名单。交互目标逐字段比较玩家位置、操控者与任务/世界/宝箱/古剑版本，不拼签名字符串；角色增删、位置恢复、显隐、泉水外观和宝箱消失时推进 `interactionRevision`。新增角色变化入口时同时推进两个修订号。任务投影由查询入口自己刷新。
- 地面拾取以位置、掉落版本和接收条件复用上次检查；背包、任务、世界、读档、调试目标、战斗就绪与存活接收者变化时重试。满蓝不阻止魔法宝石拾取。
- **任务标记按当前任务状态补建，刷新时只换图。** 任务可能在本图游玩中变为可接取；`refreshState` 对缺标记且有任务状态的角色补建头顶标记，不要只在 `createActor` 时判断一次。标记是独立的世界高深度图片（`10001`，高于树冠 `10000`），由 `afterMovement` 只更新有标记的角色位置，并同步人物显隐、透明度和舞台遮挡；不要挂回人物容器，也不要每帧投影或扫全图。同一轮只取一次 `session.marker` 结果，同时用于头顶标记和小地图；两者还要共用同一个 `markerActor` 判断；日志外任务只是不进任务日志，头顶和小地图都要显示它们的标记。进行中任务的 `talk` / `interact` 目标也要提示，目标记满后图标消失。头顶图标与小地图共用原版的 `minimap-available/active/ready` 三张图，按状态换图，不要用文字字形代替。
- **小地图创建后的第一次刷新必须执行。** 进图时第一次 `refreshState` 发生在地图创建小地图之前；刷新签名包含小地图是否就绪，避免创建后的刷新被「值没变」跳过，导致小地图一直收不到任务人物。
- 拾取提示是画布外的 DOM 元素，每帧按镜头投影定位；只有它会测量画框。
- **战斗候选和名册按逻辑帧复用。** `combatants()` 在同一逻辑帧和状态版本内共享快照，状态变化时重取，帧结束清空；名册刷新放在逻辑帧，最多晚约 60ms 生成。
- `captureStoryScene` 与剧情舞台快照共享演员外观引用，只复制必要的外壳字段；开发/测试模式下外观是冻结的，原地修改会直接报错。
- 喝泉水的回血回蓝和技能点结算调用 `domain/springs.ts` 的 `applySpringRecovery`、`grantSpringSkillPoint`；正面状态按存活上阵队员逐个施加，负面或攻防混合状态只给当前操控者。
- **任务完成和进度提示走 `showInstant`。** 只在任务簿版本变化时对比状态：有 `completion: 'all'` 的可见任务进入待交付时只提示 `任务完成：…`，这一轮不再发进度；没有完成提示时，才对目标数字增加的进行中任务提示 `任务进度：…`。对话/剧情任务已有任务窗，不重复提示。
- 场景键从 `SCENE_KEYS`（`src/application/scene-keys.ts`）取，构造、查找、启动都用它，不写裸字符串。
- 新增场景在 `src/main.ts` 注册，并接上对应的模式。
- **GM 面板的文字也走 DOM。** 游戏内 GM 面板用 `MenuTextLayer` 或 `MenuTextWriter` 输出文字；按钮只留共用皮肤和命中区，角色头顶的调试标签用 `worldToScreen` 跟随相机。
- 跨场景状态通过 `src/application/ports.ts` 的能力接口传递，不挂全局变量或模块级可变状态。
- 云存档页从存档槽页右上角进入，返回和 Escape 都回存档槽页；忙碌时只禁用云操作，返回始终可用，离开页面 abort 请求。账号/密码框直接盖在面板对应行上，输入框有焦点时场景键盘处理器让路；确认框、改名和修改密码表单打开时隐藏输入覆盖层。
- 云存档续期只在打开云页时检查：token 剩余不足 7 天才发 `/__cloud/refresh`，不在游戏循环或后台定时。
- 云存档错误只写页面状态行，不调用 `ui.error()`；场景 `shutdown` 时 abort 云请求并把待确认 Promise 落地。
- 场景键盘只桥接一次：`FormalUiScene` 把原始 `keydown` 交给 `app.inputRouter`，其他场景只注册自己的作用域，不再各挂一份 `keydown`。`MenuScene`、`StoryClassScene` 用 `menu` 作用域；`WorldScene` 的摇杆和快捷位用 `world` 作用域。场景 `shutdown` 时注销作用域。
- 场景 `shutdown` 时解绑输入、计时器和 tween，避免重启后重复触发。
- 标题页在场景恢复时重绘当前页面，确保竖屏或后台暂停期间完成的首次加载能显示菜单。
- 标题页资源加载完成后调用 `notifyBootReady()`（`application/live-update.ts`，模块级 once）。热更新壳靠这个信号提交新版本；漏掉会被当成启动失败而回退。

- 世界场景 shutdown 完成时清掉角色、地图、生成名单、交互目标、外观、订阅和进图参数引用；衣柜与伙伴外观使用权一并释放。
- 读档建战斗时由战斗状态恢复负责创建敌人；普通进图与剧情舞台恢复按访问名册创建敌人。

- 战斗状态表现只遍历 `CombatConditions.activeAppearances()` 与上次已显示的角色。状态、外观图层、显隐和倒下状态变化时更新；颜色只随战斗逻辑帧推进，循环特效名单持续重试缺失纹理。
- 生命和法力上限只由面板（等级、属性点、装备）与增益决定。被动的 `attribute` 不得是 `maxHealth`/`maxMana`，内容校验会拒绝；队伍光环、潜行和残血也不改上限，所以上限输入的缓存键只需要面板数值。逻辑帧把缓存值写回队伍成员，表现层不再单独预热。

- **挑战模式连点 5 次进入压测战场。** 压测是新建的 1 级角色，不读写任何存档槽；竞技场初始随机生成 7 只普通怪，随后每 0.9 秒在玩家周围补一只，同屏上限 40，阵亡自动满血复活。怪物按主角等级上下 2 级筛选，无候选时取最近等级；换职业后以 1 级重新开始。压测模式由 `app.pressureMode` 标记，自动存档、检查点和手动存档都拒绝写入。临时刷出的怪没有地图生成点，击杀仍按普通怪结算经验和掉落，但不写地图击杀记录。
- 加载背景与黑色遮罩同用整数层级 998，背景后创建而盖住遮罩；输入遮挡与加载界面分别使用更高层级。

- 剧情世界预取通过常驻正式界面场景加载，使用权由会话管理。正式世界静默重建复用在途请求，取得完整使用权后释放预取；同图剧情也可提前补齐人物与战斗素材。

- 神灯召唤先加载角色图集，在当前操控者附近 64 像素内寻找可达空位，再提交道具和实体；加载失败、取消或无落点时保留道具。新增商人同时更新人物和交互修订号。

- `WorldCombat` 每帧为整队记录一次实际操控者轨迹，切换控制者重建；非操控主角也使用相同跟随和安全拉回接口。归队移速最多乘 1.25，乘数作用于已经结算减速、水面和状态的速度。诊断 `partyFollow` 按成员提供搜索扩展、恢复及拉回原因计数。

- 标题云存档页在账号状态不变时只更新状态文字、存档数量和按钮可用状态，保留输入框、图框与滚动位置。

- 对白切换说话人或立绘时保留底框和跳过按钮，更新人物、姓名与正文位置。

- 标题存档删除后按槽号保留其他行和滚动区，排序变化只移动已有行。
