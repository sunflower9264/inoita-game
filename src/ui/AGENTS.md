# src/ui

`SaveSlotRename` 管理手动槽的改名输入、写入和取消。标题页和游戏内的存档页各自持有请求，按本页布局更新行标题与输入焦点。

存档页负责选择槽位、等待截图和取消迟到的保存。记录由应用层从该次保存绑定的会话生成。

界面的布局、文本与接口层：算好矩形、断行、颜色和提示内容，交给 `ui/dom` 绘制、`ui/phaser` 装配场景面板。

## 文件

- 布局：`bag-layout.ts`（背包格位）、`skill-book-layout.ts`（技能书页的图标格与右栏）、`choice-layout.ts`（选项竖排）、`control-layout.ts`（控件键位）、`item-layout.ts`（物品格与货币）、`shop-layout.ts`（商店两栏）、`quest-popup-layout.ts`（任务窗）、`description-text-layout.ts`（说明断行）、`text-layout.ts`（通用换行）、`cloud-save-layout.ts`（云存档页状态、颜色与几何）、`changelog-layout.ts`（标题页更新日志弹窗与可视窗口）、`portrait-fit.ts`（头像等比裁剪）、`viewport.ts`（屏幕尺寸、安全区、画布采样倍率与参考分辨率；`screenRectToCanvas` 将菜单预览的屏幕矩形交给游戏画布）。
- 文本与样式：`text-style.ts`（共用字体）、`text-prompt.ts`（系统键盘输入，用于存档改名）、`number-prompt.ts`（商店数量与能力点数字输入卡，负责范围校验和红色提示）、`cloud-credentials-input.ts`（云存档页内嵌的账号/密码输入框）、`dom/quest-search-input.ts`（GM 任务页左栏上方的搜索输入框）、`password-change-prompt.ts`（修改密码的当前/新/确认三项表单）、`dialogue-text.ts`（对白分页、断行与逐字显示）、`item-detail-lines.ts`（物品说明行）、`skill-detail-lines.ts`（技能说明行）、`item-result-details.ts`（操作结果说明）、`enhancement-odds-lines.ts`（强化结果句与混沌结果表）、`item-name-color.ts`（品质颜色与装备格边框）、`character-values.ts`（角色数值）。
- 接口与交互：`game-ui.ts`（UI 能力与视图接口）、`story-ui.ts`（剧情与菜单 UI 的接口、页面枚举和提示文案）、`story-ui-signature.ts`（菜单页面 viewModel 与显式签名）、`save-page.ts`（存档/读档页 controller，自行取消读档请求）、`save-slot-rename.ts`（手动槽改名输入、写入和取消）、`bag-page.ts`（背包状态、绘制与操作）、`status-page.ts`（人物与加点）、`skills-page.ts`（技能学习与自动使用设置）、`settings-page.ts`（游戏设置）、`system-page.ts`（系统菜单）、`shortcut-editor.ts`（快捷栏登记）、`shortcut-view.ts`（快捷位显示契约）、`menu-item-drag.ts`（背包与合成共用长按拖拽）、`action-press-gate.ts`（动作按钮互斥）、`common-button.ts`（通用按钮素材）、`prompt-assets.ts`（独立输入表单边框与按钮素材）、`instant-message.ts`（屏幕提示）、`quest-progress.ts`（任务完成/进度提示的纯函数）、`slot-frame.ts`（格子底图）、`world-hud.ts`（一次地图访问的屏幕控件与释放）。
- DOM 组件与文字：`dom/node.ts`、`dom/surface.ts` 提供菜单图片、文本、按钮、裁剪、滚动与原生指针；`dom/volume-slider.ts` 提供音量条；`dom/dom-ui.ts` 负责标签创建、层与坐标换算；`dom/menu-text.ts` 负责菜单页、滚动与裁剪。

## 规则

- `ui` 顶层是组合层：可以持有 `rendering` 对象和 `ui/phaser` 面板；`ui/dom` 不反向依赖它们。
- 对白翻页绘制时继承前文的颜色控制状态，分页游标和逐字进度继续使用原文位置。每页建立新的点击等待时继续沿用对白框、立绘和跳过按钮。同一个选项面板调整大小或被临时遮住时，分别保留说明和选项列表的滚动位置。
- 本目录承载布局、断行、状态和动作接口；`ui/dom` 提供 DOM/CSS/SVG 基元，`ui/phaser` 装配场景面板与输入适配。
- **头像按比例裁进框。** HUD、人物页和队员栏的头像用 `portraitFit` / `UiSurface.imageCover` 等比缩放后裁剪；背包和队伍装备页的备用人物图用 `imageContain` 完整放进预览框。
- 人物页的生命、魔法、经验三行位于立绘下方；标签、数值和百分比按对应槽位的中心线对齐，最后一行完整落在面板内。叠在彩色槽上的数值使用贴合文字宽度的深色底，保持笔画清晰。
- **画面铺满，安全区只给 UI 避让。** Android 壳用 edge-to-edge 铺满整屏；`readSafeArea()` 只用于 HUD、侧边按钮、小地图和文字的安全边，不参与画布尺寸。画布内部像素按采样倍率放大，再由 CSS 缩回画框。
- **屏幕 UI 统一用画框内的 CSS 像素。** `UiSurface` 按 `#game-frame` 的宽高与安全区将设计尺寸适配一次，节点变换后的坐标直接用于文字、图片与输入；`controlViewport()` 为 HUD、编辑器和快捷键登记提供同一份屏幕视口。采样倍率只调整游戏画布，屏幕 UI 的位置、大小和命中区域保持一致。菜单动态角色通过 `screenRectToCanvas` 接入画布，世界提示通过 `DomUi.worldToScreen` 投影到屏幕。
- 安卓手机浏览器与安装包横屏时，界面顶部以画面顶边为起点；左右和底部继续使用安全边距，竖屏及其他平台按系统提供的安全区布局。
- 左侧存档和菜单按钮与小地图共用安全区起点及缩放，从小地图下沿开始排；静态层容器不参与按钮排序。
- 人物页的加点按钮复用 `UiSurface.button` 的长按，400ms 开始、每 90ms 重复；页面离开、数字输入、失焦和取消时停止。背包拖放接收窗口原生移动、松手、取消和失焦事件；正文重绘后仍能结束手势。侧边按钮按实际内容节点判断是否已创建。
- `story-ui.ts` 只在 `attach` 时向 `app.inputRouter` 注册一个 `menu` 作用域，菜单打开时独占键盘；场景不再单独订阅 `keydown`。
- 游戏菜单切换页签时复用顶部导航按钮、图标和文字，只更新选中状态与页面正文；存读档确认框打开和取消时保留底层列表；物品操作弹层的打开、取消和数量变化保留背景页面，数量变化只更新数量文字。
- **背包的滚动位置和物品详情只属于一次进入。** 离开背包页或关闭菜单时清掉选中物品、使用结果以及背包和详情滚动缓存，重新进入从第一行开始；页内切换分类仍回顶部，切换队员和数据刷新仍保留滚动位置。
- **数字输入卡负责范围校验。** 商店数量与能力点输入共用 `number-prompt.ts`：只收数字，超限标红并禁用确定，非法值不写回。输入卡打开时菜单键盘让路，Escape/Enter 由卡片挂在 `document` 上的监听处理，焦点不在输入框时也能取消或提交；打开卡片前先停掉仍按着的加减长按。
- **背包页面绑定固定会话。** `BagPage` 管理选择、确认、异步操作和刷新；菜单保留路由和当前队员。离开或换人取消本页工作，迟到结果核对操作身份后才更新画面；共享拖拽只处理手势，落点规则交给各页面。
- **页面 controller 拥有这一页的状态和操作。** `save-page.ts` 是存档/读档页的样板：确认框、改名输入、读写请求和 Escape 分层都在 controller 里，`StoryUI` 负责路由、生命周期、共享输入和页面装配；各面板负责各自的局部更新。后续拆分页面时沿用同一方向。
- **每个菜单页面都有显式签名。** 页面 viewModel 与签名集中在 `story-ui-signature.ts`：用 `page`、`selectedMemberId`、`bag.revision`、`questBook.version`、`party` 形状、技能版本、存档槽摘要、设置值和面板自己的 `viewModel()` 拼出来，不做对象深度哈希。新增 `Page` 必须同时在 `STORY_MENU_PAGES` 和签名分支里补上；会话通知只在该页签名变化时重绘，数据没变不重绘。
- 设置页操作只更新选中状态、数值和对应动作，保留滚动区与其它控件；并列显示 30 / 60 帧上限并标出当前选择；上限切换立即生效并保留本机选择，帧率显示是独立开关。画面精度并列显示 1× / 2× / 3×，默认 1×，实际倍率不超过本机设备像素比，切换立即重配画布。帧率、暴击光效、纹理批次和画面精度等画面偏好统一放在游戏内设置页；标题页环境设置只保留音量与全屏。
- **存档槽左侧画保存时的游戏画面截图。** 截图是摘要里的 JPEG data URL，用 `imageContain` 放进固定框；没有截图时左侧留空。保存时从 Phaser 画布截取，DOM 存档页不会进入画面。
- **无法读取的存档槽要显示原因。** 标题页和存档页的 `unreadable` 行画槽名和失败原因，不能只复用空槽图；空槽仍只由 EMPTY 图表示。
- **菜单预览共用角色画面的外观持有规则。** 背包页和队伍页用 `previewAppearance` 取外观，`createCharacter` 创建的角色自行借住合成外观；`LiveCharacterPreview.detach`/`destroy` 销毁角色时归还，隐藏期间继续持有。
- 关闭调试界面或切页时清理面板、预览与文字；回标题时同时解除菜单持有的会话引用。
- `src/ui/` 顶层与 `ui/dom/` 只用 `import type Phaser`；运行时 Phaser 仅限 `ui/phaser/` 的视图适配文件。
- **DOM 文字统一带 `dom-label`。** `DomUi.label` 会自动补上这个类，它负责绝对定位、不换行和禁用指针事件；调用方只加自己的样式类。压在游戏画面上的文字用 `#ui-world`/`#ui-hud` 的软阴影；菜单文字按背景需要设置对比样式。
- **定宽居中文字要显式写 `align:'center'`。** `MenuTextLayer` 对定宽文字默认左对齐；同时用了 `anchorX:.5` 和 `width` 的按钮文字、数量行和底部说明若不写对齐，整段文字会贴在自己盒子的左边，看起来像没在按钮里。
- **弹层打开时页面文字整体压暗，被盖住的部分按实际盒宽裁剪。** DOM 文字在所有画布表面之上，弹层黑底挡不住标签；用 `MenuTextSpec.dim` 压暗页面文字，用 `occlude` + `clip-path` 只裁掉与不透明弹层相交的那一段，不要整条删除，也不要整页隐藏。页面渲染函数在弹层打开时仍要输出页面文字，再额外输出弹层文字；不要再写「弹层打开就只输出弹层那一份」的二选一分支。单行文字拿不到稳定盒宽时，只有整条落在弹层里才隐藏。
- **页面坐标和弹层坐标可以在同一页混用。** 更新日志这类画在弹层上的文字给 `MenuTextSpec.space='modal'`，`MenuTextLayer` 用构造参数里的弹层坐标换算；页面文字保持默认页面坐标，`dim`/`occlude` 仍按页面坐标计算。
- **菜单弹层的内容区一律不透明。** `drawPopupPanel` 的黑底、说明面板、确认横带和 `v.frame` 弹层都用 alpha 1；只有铺满全屏的遮罩可以半透明（65%）。正文超过可用高度时用 `ScrollArea` + DOM `clip` 滚动，标题和按钮固定在滚动区外。
- **滚动文字用 `clip` 交给浏览器裁边。** `MenuTextLayer` 会为同一组上下边界建一个 `overflow:hidden` 的容器，滚动只移动标签；新增可滚动面板时同时给 `scroll` 和 `clip`，不要只靠 `y` 判断显隐。
- **菜单滚动区由 `StoryUI.scroll` 统一登记。** 每个滚动区只保留一个文字刷新入口：面板自己的 `onScroll` 负责刷新文字和自己的偏移/状态；没有面板 `onScroll` 的内部滚动区使用 `StoryUI.scroll` 放的默认 `onScroll`。`MenuTextLayer.refresh()` 会把同一帧的刷新合并为一次。不要绕过 `StoryUI.scroll` 自建滚动区。
- **全屏遮罩用 `DomUi.setOccluded`。** 加载页、阵亡面板、跨图黑幕、横屏提示和挂起时，由 `uiOcclusion`（`game-ui.ts`）判断并收起 world/hud/screen 三层；加载页自己的文字放在 overlay 层。新增全屏界面时不要再让各页面各自猜显隐。
- **跳过补画黑底与跨图重建黑幕分开。** `setSkipBackdrop` 只盖画面，不进入 `uiOcclusion`，也不隐藏任务窗和选择框：跳过到弹窗时先盖黑底、补画对应剧情画面、补完撤掉再弹窗。`setWorldRebuildCover` 继续按原规则隐藏这些弹层。
- 文本宽度、换行、选项高度和滚动范围在交给显示组件前算完，绘制层只按结果摆放。
- 快捷位显示契约由 `shortcut-view.ts` 提供，场景和控件共用技能、物品与冷却快照。
- **快捷键登记屏画出攻击按钮。** 游戏内控件在菜单打开时整层收起，登记屏要与控件共用同一份布局：先按 `positions.attack`（含用户倍率）画攻击按钮，再画六个圆槽和换组键，轮盘中心不会空一块。登记快捷键或换组时保留控件，只更新变化的槽位图标。
- 控件尺寸从 `control-layout.ts` 的 `CONTROL_SIZES` 取；D-pad 视觉与布局用 `moveDpad` 274×274，摇杆用 `move` 210×210。
- **长按按钮用 `UiSurface.button` 的 `hold` 选项。** 按住超过 `delayMs` 后每 `intervalMs` 执行一次，松手不再补一次点击；按钮禁用时立刻停。商店数量箭头用 350ms/80ms。
- **摇杆的指针状态必须能自愈。** 新的 `pointerdown` 接管旧指针；`pointerup`、`pointercancel`、`lostpointercapture`，以及移动事件里 `event.buttons === 0` 都要回中，避免丢失 `pointerup` 后一直朝某个方向走。
- 用户调过的控件大小按控件位置保存成倍率（`scale`，0.6–2.0），解析时与屏幕适配缩放分开乘。倍率跟着 `slot-0`…`slot-5` 这些位置走，切换技能组或换成技能/物品内容都不改变它。
- 字体、字号和颜色取 `text-style.ts`，新面板不再另建一套字体栈。
- 说明面板底部动作 1–3 个排一横排；4 个用 2×2，5–6 个用 2×3，几何由 `descriptionActionLayout` 统一给出。动作文字按按钮中间可用宽度缩小字号并居中，完整文案保持在按钮内部。
- **物品操作弹层按正文高度定高。** 先量物品名、说明、结果行和奖励行，再决定弹层高度（不低于原版 450×350）；数量行固定在底部按钮上方，正文只在它上面滚动，长说明不会截断下半截，`−/＋/全部` 也不会掉出框外。
- 新增面板先在这里补几何和文本函数，再在 `ui/phaser` 装配、在 `ui/dom` 补基元。
- **融合器预览按当前页签档位取色。** 混沌/深渊混沌预览的标题颜色和格子边框由页签档位决定；合成完成后的背包按实例真实档位显示。
- 云存档页的状态颜色和面板几何从 `cloud-save-layout.ts` 取；账号/密码输入用 `cloud-credentials-input.ts` 的内嵌输入框，直接定位在面板对应行上，不用独立弹层。存档改名继续用 `TextPrompt`。
- **GM 任务页搜索框在左栏上方。** 输入框是挂在 `#game-frame` 的原生 `input`（`QUEST_SEARCH`：30,8,500×46，与页签同一行），左右两栏内容从 y=70 开始；placeholder 用 `.875em` 单独缩小（约 14px），输入文字仍按画框倍率且不低于 16px。输入框有焦点时 `story-ui.ts` 的菜单键盘整块让路，Enter 打开第一条结果，Escape 只清空并 blur。画框缩放/旋转时 `story-ui.layout()` 调 `gmPanel.layoutSearch()` 重贴；输入框高度不低于 22px，`keyCode 229` 视为输入法确认。任务名和说明统一经 `readableStoryText` 转成可读文本，搜索同时匹配原始标题和可读标题。
- **强化结果先写人话。** 普通卷轴写成「当前 +N：X% 到 +N+1，Y% 到 +N+2」；混沌卷轴写成三行结果表。概率文案统一由 `enhancement-odds-lines.ts` 生成，面板只负责画。
- **菜单子页面保留底层。** 强化台、合成台、技能书这类从菜单进入的子页面用 `page` 渲染在 `body` 上；`surface`/`body` 继续可见，只把说明层让位，不要隐藏整层再铺纯黑遮罩。
- **技能书页复用技能目录的图标语言。** 左框只列当前可升级的技能（4×4 图标格，一屏放下），没有可升级技能时显示「暂无可升级技能」；右框显示等级变化与下一级数值预览，确认后才消耗技能书。封印书开封后在背包结果层显示「已永久解锁」、技能名称和职业，保留其他物品格与滚动位置。
- **游戏内界面不写解释性文案。** 这是游戏而不是说明书：格子、按钮和页面只呈现状态与结果，用户明确要求时才加「×＝可用」这类说明文字。
- **操作结果提示走 `GameUI.showInstant`。** 泉水恢复、任务完成、任务进度和菜单里的「脱离卡死」都用这一套屏幕提示；`toast` 用于加载、准备和非阻塞错误短提示。
- 背包点击「召唤神灯商人」后等待地图召唤成功并关闭背包，点击地图上的商人交易；失败保留神灯，丢弃仍通过数量确认。
- **操作只更新受影响的内容。** 子页面处理自己的状态变化和弹层，会话通知与动作回调共用更新边界，保留未变化的节点及滚动区。
- 队员外观准备完成后只更新背包人物预览；已经切到其他队员或页面时忽略迟到结果。
- 背包和队伍装备页使用衣柜合成外观播放待机角色，未准备好时显示备用人物图。
- **背包页的数据变化只改变化的格子。** 页已画好时，物品按实例、空格按袋位复用；金额只换数字，装备只换图，说明面板单独重画。新增和删除物品只动对应格子，切换分类保留图框、人物和分类按钮并将背包滚回顶部。队员人数或顺序变化时重新装配页面；确认弹层独立显示，保留底层页面。
- **整理按钮使用共用按钮皮肤。** 背包分类选中时用淡色底，侧栏与商人、合成台和强化台共用绘制。
- **说明面板动作行用文字按钮。** `renderItemDetail` 的动作统一走 `v.button(label, ...)` 的共用按钮皮肤，不给动作塞 `item-equip`/`item-discard` 这类烘焙图。
- **阵亡面板的「读取存档」复用菜单的读档页。** 打开时暂时收起阵亡面板并让出 `defeat` 锁，读档页关闭后恢复同一个面板；不要另写一套存档列表。

### 页面更新约定

- **背包**：切换队员时保留背包格、滚动与固定控件；物品说明关闭并恢复被遮住的内容，操作结果继续保留，再更新装备槽、人物和等级职业文字。穿脱装备准备期间保留页面，完成后刷新一次；文字按位置、物品显示值和说明遮挡状态复用，外观引用未变时保留人物预览。确认物品操作及关闭使用结果时保留未变化的物品格、按钮和滚动区，结果显示在独立说明层。
- **人物与队伍**：人物页切换队员保留图框和队员按钮，更新立绘、数值和加点区域；有未确认加点时单独显示确认框。加点、长按加减和能力重置更新数字与按钮可用状态，保留人物图和未变化控件；确认失败时保留确认框和人物页面，只更新错误文字。佣兵能力点与主角共用加点、确认和重置交互。队伍详情页签只更新选中状态和详情，保留名册及页签；技能详情和放逐确认弹层独立更新，打开或取消时保留底层页面和滚动位置。队员上阵或转为候补时保留名册和页签，只更新上阵标记、身份文字及当前详情；切换名册页保留剧情队员、名册切换按钮和右侧页签；放逐后只更新变化的名册槽及当前详情。
- **技能**：切换队员或目录、AI、设置页签时保留图框、队员栏和页签，只替换相应技能内容；选择技能时保留技能列表和滚动位置，只更新选中标记与说明；打开或取消技能初始化确认框保留技能页面；修改 AI 自动使用频率只更新对应按钮。主角和佣兵技能页均显示本人剩余技能点，并共用学习与设置交互；「能力初始化」按钮在左侧内容区水平、垂直居中，确认操作绑定打开时的成员。剧情伙伴保留伙伴技能标题与自动成长方式；下一级提示读取实际自动成长门槛，技能书解锁的技能不显示自动成长等级。
- **技能书**：选择技能时保留图框和技能格，仅更新选中标记及详情，释放上一份详情滚动区；使用后保留仍可升级的技能格，只更新等级标记、消耗数量和详情。技能书页显示当前佣兵名字与佣兵技能数值，选技能和使用时保留未变化的图标与边框。学习技能和取消技能快捷键时保留技能目录、页签和滚动区，只更新等级、技能点和详情。
- **商店**：商品分类只替换变化的货架商品，保留分类按钮、背包及滚动区；切换后失效的商品详情及时关闭。数量行按物品图标、减箭头、居中数量、加箭头排列，数量文字与输入热区共用 `shop-layout.ts` 的矩形。背包筛选保留货架、筛选按钮、滚动区和仍显示的物品格，只调整变化的格子。单件交易完成后按商品和背包物品身份更新格子及金额，保留未变化的货架、背包和导航。批量出售的选择标记、合计和按钮就地更新，结算后保留未出售的物品格与滚动区；进入或退出批量模式及批量筛选时保留货架、切换按钮、滚动区和仍符合条件的物品格。物品上锁和解锁只更新锁标记与详情，清理模式下同步移除不再符合条件的装备。进入或退出商店清理模式保留货架、背包滚动区与未变化的装备格，清理工具单独显示和释放。
- **清理装备**：布局由 `shop-layout.ts` 提供，整页顶部返回、合计与出售，背包框上方等级和五档独立品质，品质按钮以共用按钮的选中样式区分状态；默认白装及当前查看角色等级，等级加减支持 350ms/80ms 长按。装备上锁/解锁在详情动作行，格子与装备槽通过 `slot-frame.ts` 共用锁标记，操作不弹提示；动作多行使用 `descriptionActionLayout`。没有可售装备时只显示空格子。调整等级或品质时保留筛选控件和滚动区，按装备身份更新候选格、数量与合计。
- **合成与强化**：合成背包切换分类时保留滚动区、分类按钮和未变化的物品格，拖放目标随格子位置同步；合成模式和配方切换只更新工作区，模式按钮和背包保持原位，离开配方列表时释放其滚动区；结算按变化更新背包格、材料与金额，保留未变化的物品、功能按钮及滚动区。强化页切换功能时保留左侧摘要、功能按钮和两侧滚动区，只替换受影响的材料和操作内容；强化、镶嵌和净化结算只更新装备摘要、变化的材料格及操作内容，保留其他格子、页签和滚动区。
- **存档与云存档**：存档改名打开、取消或提交时保留存档列表，提交只更新对应标题；关闭页面或切换会话时请求失效，迟到的输入结果不再修改存档或当前页面。存档行提供自己的主按钮，方便名称变化时只更新该行标题和按钮标签。开始读取存档时只关闭确认框并锁定输入，存档列表保留到读取完成或界面关闭。游戏内删除存档时按槽号保留其他行，排序变化只移动已有行与文字；保存和读取提示独立于存档列表，写入后只替换目标槽并按时间移动其他槽位。云存档状态行始终保留文字节点，连接状态改变时只更新内容和颜色；标题云存档页在账号状态不变时只更新状态文字、存档数量和按钮可用状态，保留输入框、图框与滚动位置。
- **调试面板**：面板内更新保留顶部页签，只释放和重建当前内容区；面板关闭后的异步结果不能重新打开或改写当前页面。道具筛选复用网格、筛选按钮和数量控件，切换后更新可见格内容并关闭原详情；道具选择和关闭详情保留网格、滚动区和数量按钮，只更新选中状态、摘要与详情。人物操作保留角色栏和操作按钮，只更新受影响的数值及状态；发放道具或金币时保留网格、滚动区和操作按钮；状态操作保留原按钮与布局，异步上报结果只写回仍有效的页面。
- **其他页面**：键位设置中的捕获、取消、绑定和恢复默认只更新按钮状态及文字，保留页面图框和按钮。控件布局编辑器切换移动和缩放模式时保留工具栏、控件及键盘焦点。挑战模式的小地图下方提供「调试」入口（由 `pressure-debug-panel.ts` 独立承接）：透明无底框、保留全屏暗色遮罩，顶部提供「职业」「怪物」双页签与常驻关闭按钮，双页内容一次性构建（切页、选职与调参数均就地更新状态与显隐，不重建节点、零闪烁）；「职业」页签保留缩小职业图标居中双行排布并与底部按钮留足净空，「怪物」页签采用左标签右控件的设置行排布，支持怪物数量上限（0–100，快捷挡位、长按加减与 `NumberPrompt` 数字输入）和固定最大血量（默认、常用挡位与 `NumberPrompt` 自定义正整数）及一键恢复默认；打开期间暂停世界，换职业确认后以新职业重新开始。独立输入弹窗（数量、能力点、存档改名、修改密码）通过 `dom/prompt-shell.ts` 共用原版图框、按钮皮肤及字体，几何与短屏滚动见 `ui/dom/AGENTS.md`。剧情专属装备的卸下按钮按 `Bag.unequipProblem` 禁用；替换按钮与拖拽共用背包装备判定，保护当前穿戴的专属装备。

### 页面与场景职责

- `status-page.ts` 持有固定会话的人物页、加点草稿、数字输入和确认流程；普通离开先处理草稿，释放会话直接丢弃草稿并清理页面。
- `title-menu-controller.ts` 管理标题页面树、存档槽、云存档、设置和更新日志的状态、请求与 DOM；`class-selection-page.ts` 管理职业选择和预览（未开启调试模式时过滤 `debugOnly` 职业并维持 `960×640`，开启调试模式时于狂战士右侧水平对齐放置调试职业并对称扩宽容器避免窄屏裁切）。场景连接启动、恢复与关闭，页面关闭后忽略迟到资源。
- `formal-ui-view.ts` 连接剧情显示组件；`formal-presentation.ts` 只计算显示优先关系；`formal-choice-view.ts` 独立持有选项按钮与滚动；`formal-modal-view.ts` 管理加载、阵亡和横屏提示。
- `world-hud.ts` 持有一次地图访问的屏幕控件、布局、操作模式订阅和释放；状态订阅绑定装配时的会话，旧地图输入不能操作新会话。
- `skills-page.ts` 持有固定会话的技能选择、学习和初始化确认；`settings-page.ts`、`system-page.ts` 各自管理页面节点与文字；`shortcut-editor.ts` 持有一次登记的对象、分组和槽位。菜单只提供公共显示设施与导航。
- `SavePage` 持有读档请求及忙碌状态；离开页面取消请求，迟到的旧读档失败不能覆盖新的请求或提示。手动存档成功写入后调用宿主的 `afterManualSave`，`StoryUI` 用它把“保存成功”接成剧情跳转待办；离开存档页或关闭菜单时清掉待办。调试任务页把已预览的现场计划交给存档页，保存成功后执行同一份计划，跳转失败时在当前界面显示原因。
- 页面清理可重复调用；请求取消后不能更新新页面，已提交的游戏操作仍以领域对象的结果为准。
