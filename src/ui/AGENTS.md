# src/ui

界面的布局、文本与接口层：算好矩形、断行、颜色和提示内容，交给 `src/ui/dom/` 绘制。

## 文件

- 布局：`bag-layout.ts`（背包格位）、`skill-book-layout.ts`（技能书页的图标格与右栏）、`choice-layout.ts`（选项竖排）、`control-layout.ts`（控件键位）、`item-layout.ts`（物品格与货币）、`shop-layout.ts`（商店两栏）、`quest-popup-layout.ts`（任务窗）、`description-text-layout.ts`（说明断行）、`text-layout.ts`（通用换行）、`cloud-save-layout.ts`（云存档页状态、颜色与几何）、`changelog-layout.ts`（标题页更新日志弹窗与可视窗口）、`portrait-fit.ts`（头像等比裁剪）、`viewport.ts`（屏幕尺寸、安全区、画布采样倍率与参考分辨率；`screenRectToCanvas` 将菜单预览的屏幕矩形交给游戏画布）。
- 文本与样式：`text-style.ts`（共用字体）、`text-prompt.ts`（系统键盘输入，用于存档改名）、`cloud-credentials-input.ts`（云存档页内嵌的账号/密码输入框）、`password-change-prompt.ts`（修改密码的当前/新/确认三项表单）、`dialogue-text.ts`（对白分页、断行与逐字显示）、`item-detail-lines.ts`（物品说明行）、`skill-detail-lines.ts`（技能说明行）、`item-result-details.ts`（操作结果说明）、`enhancement-odds-lines.ts`（强化结果句与混沌结果表）、`item-name-color.ts`（品质颜色与装备格边框）、`character-values.ts`（角色数值）。
- 接口与交互：`game-ui.ts`（UI 能力与视图接口）、`story-ui.ts`（剧情与菜单 UI 的接口、页面枚举和提示文案）、`story-ui-signature.ts`（菜单页面 viewModel 与显式签名）、`save-page.ts`（存档/读档页 controller）、`action-press-gate.ts`（动作按钮互斥）、`common-button.ts`（通用按钮素材）、`instant-message.ts`（屏幕提示）、`quest-progress.ts`（任务完成/进度提示的纯函数）、`slot-frame.ts`（格子底图）。
- DOM 组件：`dom/node.ts`、`dom/surface.ts` 提供菜单图片、文本、按钮、裁剪、滚动与原生指针；`dom/volume-slider.ts` 提供音量条。
- DOM 文字：`dom/dom-ui.ts`（标签创建、层与坐标换算）、`dom/menu-text.ts`（菜单页、滚动与裁剪）。

## 规则

- 对白翻页绘制时继承前文的颜色控制状态，分页游标和逐字进度继续使用原文位置。


- 本目录承载布局、断行、状态和动作接口；屏幕组件的 DOM 绘制与输入在 `src/ui/dom/`。
- **头像按比例裁进框。** HUD、人物页和队员栏的头像用 `portraitFit` / `UiSurface.imageCover` 等比缩放后裁剪；背包和队伍装备页的备用人物图用 `imageContain` 完整放进预览框。
- 人物页的生命、魔法、经验三行位于立绘下方；标签、数值和百分比按对应槽位的中心线对齐，最后一行完整落在面板内。叠在彩色槽上的数值使用贴合文字宽度的深色底，保持笔画清晰。
- **画面铺满，安全区只给 UI 避让。** Android 壳用 edge-to-edge 铺满整屏；`readSafeArea()` 只用于 HUD、侧边按钮、小地图和文字的安全边，不参与画布尺寸。画布内部像素按采样倍率放大，再由 CSS 缩回画框。
- **屏幕 UI 统一用画框内的 CSS 像素。** `UiSurface` 按 `#game-frame` 的宽高与安全区将设计尺寸适配一次，节点变换后的坐标直接用于文字、图片与输入；`controlViewport()` 为 HUD、编辑器和快捷键登记提供同一份屏幕视口。采样倍率只调整游戏画布，屏幕 UI 的位置、大小和命中区域保持一致。菜单动态角色通过 `screenRectToCanvas` 接入画布，世界提示通过 `DomUi.worldToScreen` 投影到屏幕。
- 安卓手机浏览器与安装包横屏时，界面顶部以画面顶边为起点；左右和底部继续使用安全边距，竖屏及其他平台按系统提供的安全区布局。
- 左侧存档和菜单按钮与小地图共用安全区起点及缩放，从小地图下沿开始排；静态层容器不参与按钮排序。
- `story-ui.ts` 的长按加点与背包拖放接收窗口原生移动、松手、取消和失焦事件；正文重绘后仍能结束手势。侧边按钮按实际内容节点判断是否已创建。
- `story-ui.ts` 只在 `attach` 时向 `app.inputRouter` 注册一个 `menu` 作用域，菜单打开时独占键盘；场景不再单独订阅 `keydown`。
- 游戏菜单切换页签时复用顶部导航按钮、图标和文字，只更新选中状态与页面正文；存读档确认框打开和取消时保留底层列表；物品操作弹层的打开、取消和数量变化保留背景页面，数量变化只更新数量文字。
- **页面 controller 拥有这一页的状态和操作。** `save-page.ts` 是存档/读档页的样板：确认框、改名输入、读写请求和 Escape 分层都在 controller 里，`StoryUI` 负责路由、生命周期、共享输入和页面装配；各面板负责各自的局部更新。后续拆分页面时沿用同一方向。
- **每个菜单页面都有显式签名。** 页面 viewModel 与签名集中在 `story-ui-signature.ts`：用 `page`、`selectedMemberId`、`bag.revision`、`questBook.version`、`party` 形状、技能版本、存档槽摘要、设置值和面板自己的 `viewModel()` 拼出来，不做对象深度哈希。新增 `Page` 必须同时在 `STORY_MENU_PAGES` 和签名分支里补上；会话通知只在该页签名变化时重绘，数据没变不重绘。
- 设置页操作只更新选中状态、数值和对应动作，保留滚动区与其它控件；并列显示 30 / 60 帧上限并标出当前选择；上限切换立即生效并保留本机选择，帧率显示是独立开关。画面精度并列显示 1× / 2× / 3×，默认 1×，实际倍率不超过本机设备像素比，切换立即重配画布。帧率、暴击光效、纹理批次和画面精度等画面偏好统一放在游戏内设置页；标题页环境设置只保留音量与全屏。
- **存档槽左侧画保存时的游戏画面截图。** 截图是摘要里的 JPEG data URL，用 `imageContain` 放进固定框；旧档没有截图时左侧留空，不再用职业立绘顶替。保存时从 Phaser 画布截取，DOM 存档页不会进入画面。
- 关闭调试界面或切页时清理面板、预览与文字；回标题时同时解除菜单持有的会话引用。调试任务跳转失败后重新打开调试面板并显示原因。
- 这里不运行时导入 `phaser`；需要 Phaser 类型时用 `import type`，写法参考 `story-ui.ts`。
- **DOM 文字统一带 `dom-label`。** `DomUi.label` 会自动补上这个类，它负责绝对定位、不换行和禁用指针事件；调用方只加自己的样式类。压在游戏画面上的文字用 `#ui-world`/`#ui-hud` 的软阴影；菜单文字按背景需要设置对比样式。
- **定宽居中文字要显式写 `align:'center'`。** `MenuTextLayer` 对定宽文字默认左对齐；同时用了 `anchorX:.5` 和 `width` 的按钮文字、数量行和底部说明若不写对齐，整段文字会贴在自己盒子的左边，看起来像没在按钮里。
- **弹层打开时页面文字整体压暗，被盖住的部分按实际盒宽裁剪。** DOM 文字在所有画布表面之上，弹层黑底挡不住标签；用 `MenuTextSpec.dim` 压暗页面文字，用 `occlude` + `clip-path` 只裁掉与不透明弹层相交的那一段，不要整条删除，也不要整页隐藏。页面渲染函数在弹层打开时仍要输出页面文字，再额外输出弹层文字；不要再写「弹层打开就只输出弹层那一份」的二选一分支。单行文字拿不到稳定盒宽时，只有整条落在弹层里才隐藏。
- **页面坐标和弹层坐标可以在同一页混用。** 更新日志这类画在弹层上的文字给 `MenuTextSpec.space='modal'`，`MenuTextLayer` 用构造参数里的弹层坐标换算；页面文字保持默认页面坐标，`dim`/`occlude` 仍按页面坐标计算。
- **菜单弹层的内容区一律不透明。** `drawPopupPanel` 的黑底、说明面板、确认横带和 `v.frame` 弹层都用 alpha 1；只有铺满全屏的遮罩可以半透明（65%）。正文超过可用高度时用 `ScrollArea` + DOM `clip` 滚动，标题和按钮固定在滚动区外。
- **滚动文字用 `clip` 交给浏览器裁边。** `MenuTextLayer` 会为同一组上下边界建一个 `overflow:hidden` 的容器，滚动只移动标签；新增可滚动面板时同时给 `scroll` 和 `clip`，不要只靠 `y` 判断显隐。
- **菜单滚动区由 `StoryUI.scroll` 统一登记。** 它建区时会给 `ScrollArea` 加一条自动刷新 DOM 文字的监听；面板的 `onScroll` 只负责记自己的偏移和状态，不要再为文字单独调用刷新，也不要在菜单页绕过 `StoryUI.scroll` 自建滚动区。
- **全屏遮罩用 `DomUi.setOccluded`。** 加载页、阵亡面板、跨图黑幕、横屏提示和挂起时，由 `uiOcclusion`（`game-ui.ts`）判断并收起 world/hud/screen 三层；加载页自己的文字放在 overlay 层。新增全屏界面时不要再让各页面各自猜显隐。
- 文本宽度、换行、选项高度和滚动范围在交给显示组件前算完，绘制层只按结果摆放。
- 快捷位显示契约由 `shortcut-view.ts` 提供，场景和控件共用技能、物品与冷却快照。
- **快捷键登记屏画出攻击按钮。** 游戏内控件在菜单打开时整层收起，登记屏要与控件共用同一份布局：先按 `positions.attack`（含用户倍率）画攻击按钮，再画六个圆槽和换组键，轮盘中心不会空一块。
- 控件尺寸从 `control-layout.ts` 的 `CONTROL_SIZES` 取；D-pad 视觉与布局用 `moveDpad` 274×274，摇杆用 `move` 210×210。
- **长按按钮用 `UiSurface.button` 的 `hold` 选项。** 按住超过 `delayMs` 后每 `intervalMs` 执行一次，松手不再补一次点击；按钮禁用时立刻停。商店数量箭头用 350ms/80ms。
- **摇杆的指针状态必须能自愈。** 新的 `pointerdown` 接管旧指针；`pointercancel`、`gameout`、以及 `isDown=false` 的移动事件都要回中，避免丢失 `pointerup` 后一直朝某个方向走。
- 用户调过的控件大小按控件位置保存成倍率（`scale`，0.6–2.0），解析时与屏幕适配缩放分开乘。倍率跟着 `slot-0`…`slot-5` 这些位置走，切换技能组或换成技能/物品内容都不改变它。
- 字体、字号和颜色取 `text-style.ts`，新面板不再另建一套字体栈。
- 说明面板底部动作 1–3 个排一横排；4 个用 2×2，5–6 个用 2×3，几何由 `descriptionActionLayout` 统一给出。
- 说明面板动作文字按按钮中间可用宽度缩小字号并居中，完整文案保持在按钮内部。
- **物品操作弹层按正文高度定高。** 先量物品名、说明、结果行和奖励行，再决定弹层高度（不低于原版 450×350）；数量行固定在底部按钮上方，正文只在它上面滚动，长说明不会截断下半截，`−/＋/全部` 也不会掉出框外。
- 新增面板先在这里补几何和文本函数，再在 `src/ui/dom/` 实现绘制与输入。
- **融合器预览按当前页签档位取色。** 混沌/深渊混沌预览的标题颜色和格子边框由页签档位决定；合成完成后的背包按实例真实档位显示。
- 云存档页的状态颜色和面板几何从 `cloud-save-layout.ts` 取；账号/密码输入用 `cloud-credentials-input.ts` 的内嵌输入框，直接定位在面板对应行上，不用独立弹层。存档改名继续用 `TextPrompt`。
- **强化结果先写人话。** 普通卷轴写成「当前 +N：X% 到 +N+1，Y% 到 +N+2」；混沌卷轴写成三行结果表。概率文案统一由 `enhancement-odds-lines.ts` 生成，面板只负责画。
- **菜单子页面保留底层。** 强化台、合成台、技能书这类从菜单进入的子页面用 `page` 渲染在 `body` 上；`surface`/`body` 继续可见，只把说明层让位，不要隐藏整层再铺纯黑遮罩。
- **技能书页复用技能目录的图标语言。** 左框只列当前可升级的技能（4×4 图标格，一屏放下），没有可升级技能时显示「暂无可升级技能」；右框显示等级变化与下一级数值预览，确认后才消耗技能书。
- **游戏内界面不写解释性文案。** 这是游戏而不是说明书：格子、按钮和页面只呈现状态与结果，用户明确要求时才加「×＝可用」这类说明文字。
- **操作结果提示走 `GameUI.showInstant`。** 泉水恢复、任务完成、任务进度和菜单里的「脱离卡死」都用这一套屏幕提示；`toast` 只用于加载、准备之类的短提示。
- 背包点击「召唤神灯商人」后等待地图召唤成功并关闭背包，点击地图上的商人交易；失败保留神灯，丢弃仍通过数量确认。
- **操作只更新受影响的内容。** 子页面处理自己的状态变化和弹层，会话通知与动作回调共用更新边界，保留未变化的节点及滚动区。
- 队员外观准备完成后只更新背包人物预览；已经切到其他队员或页面时忽略迟到结果。
- 背包和队伍装备页使用衣柜合成外观播放待机角色，未准备好时显示备用人物图。
- 背包页切换队员时保留背包格、滚动与固定控件；物品说明关闭并恢复被遮住的内容，操作结果继续保留，再更新装备槽、人物和等级职业文字。
- 穿脱装备准备期间保留页面，完成后刷新一次；背包格按位置、物品显示值和说明遮挡状态复用文字描述，外观引用未变时保留正在播放的人物预览。
- **背包页的数据变化只改变化的格子。** 页已画好时，物品按实例、空格按袋位复用；金额只换数字，装备只换图，说明面板单独重画。新增和删除物品只动对应格子，切换分类保留图框、人物和分类按钮并将背包滚回顶部。队员人数或顺序变化时重新装配页面；确认弹层独立显示，保留底层页面。
- 人物页切换队员时保留图框和队员按钮，更新立绘、数值和加点区域；有未确认加点时单独显示确认框。
- 技能页切换队员或目录、AI、设置页签时保留图框、队员栏和页签，只替换相应技能内容；选择技能时保留技能列表和滚动位置，只更新选中标记与说明；打开或取消技能初始化确认框保留技能页面；修改 AI 自动使用频率只更新对应按钮。
- **整理按钮使用共用按钮皮肤。** 背包分类选中时用淡色底，侧栏与商人、合成台和强化台共用绘制。
- **说明面板动作行用文字按钮。** `renderItemDetail` 的动作统一走 `v.button(label, ...)` 的共用按钮皮肤；不再给动作塞 `item-equip`/`item-discard` 这类烘焙图。
- **阵亡面板的「读取存档」复用菜单的读档页。** 打开时暂时收起阵亡面板并让出 `defeat` 锁，读档页关闭后恢复同一个面板；不要另写一套存档列表。

## 验证

```bash
npm run typecheck
npm test -- tests/bag-layout.test.ts tests/choice-layout.test.ts
```

- 清理装备布局由 `shop-layout.ts` 提供：整页顶部返回、合计与出售，背包框上方等级和五档独立品质，品质按钮以共用按钮的选中样式区分状态。默认白装及当前查看角色等级；等级加减支持 350ms/80ms 长按。装备上锁/解锁在详情动作行，格子与装备槽通过 `slot-frame.ts` 共用锁标记，操作不弹提示；动作多行使用 `descriptionActionLayout`。没有可售装备时只显示空格子。

- 人物页的佣兵能力点与主角共用加点、确认和重置交互。

- 挑战模式的小地图下方提供换职业入口；选择期间暂停世界，确认后以新职业重新开始。

- 队伍详情页签只更新选中状态和详情，保留名册及页签；技能详情和放逐确认弹层独立更新，打开或取消时保留底层页面和滚动位置。

- 商店商品分类只替换变化的货架商品，保留分类按钮、背包及滚动区；切换后失效的商品详情及时关闭。

- 合成背包切换分类时保留滚动区、分类按钮和未变化的物品格，拖放目标随格子位置同步。

- 商店背包筛选保留货架、筛选按钮、滚动区和仍显示的物品格，只调整变化的格子。

- 调试面板内更新保留顶部页签，只释放和重建当前内容区；面板关闭后的异步结果不能重新打开或改写当前页面。

- 合成模式和配方切换只更新工作区，模式按钮和背包保持原位；离开配方列表时释放其滚动区。

- 调试剧情切换任务和任务预览返回时保留任务列表与滚动位置，只更新选中状态和右侧详情。

- 调试道具选择和关闭详情保留网格、滚动区和数量按钮，只更新选中状态、摘要与详情。

- 商店单件交易完成后按商品和背包物品身份更新格子及金额，未变化的货架、背包和导航继续保留。

- 强化页切换功能时保留左侧摘要、功能按钮和两侧滚动区，只替换受影响的材料和操作内容。

- 强化、镶嵌和净化结算只更新装备摘要、变化的材料格及操作内容，保留其他格子、页签和滚动区。

- 合成结算按变化更新背包格、材料与金额，保留未变化的物品、功能按钮及滚动区。

- 键位设置中的捕获、取消、绑定和恢复默认只更新按钮状态及文字，保留页面图框和按钮。

- 存档改名打开或取消时保留存档列表；关闭页面或切换会话时请求失效，迟到的输入结果不再修改存档或当前页面。

- 人物加点、长按加减和能力重置更新数字与按钮可用状态，保留人物图和未变化控件。

- 商店批量出售的选择标记、合计和按钮就地更新，结算后保留未出售的物品格与滚动区。
