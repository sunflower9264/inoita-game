# src/ui/dom

屏幕界面的 DOM 组件、图片、输入和生命周期。外观沿用原版素材，布局与游戏状态取自上层接口。

- 图片使用资源版本号；同一图集共享加载，组件关闭释放持有的资源。
- 图片或图集加载失败时写 `asset-load-error` 诊断（`source` 为 `dom-image` 或 `dom-atlas`），真机裁剪素材后据此确认没有漏图。
- 组件按稳定标识复用节点，只更新变化的内容、位置和可见性。
- 任务标记和拾取提示在同一游戏帧共用画框、画布的尺寸与位置测量；镜头坐标和倍率始终实时读取，视口重排立即使测量失效。
- **DOM 布局与输入统一使用屏幕 CSS 坐标。** `uiMount` 用 `inset:0` 铺满画框，并用 `z-index:0` 将图片与控件排在独立文字层下方。`UiSurface.layout` 只按画框可用空间缩放设计尺寸；`UiNode` 的根变换输出屏幕坐标，原生指针减去画框偏移后进入同一套命中与拖动计算。1×、2×、3× 采样下的界面布局保持一致。
- 图片与文字在同一组件内排层；确认框和全屏遮挡同时管理显示和输入。全屏背景及遮罩取画框 CSS 宽高，弹层根节点按本次内容尺寸更新；`UiSurface.width/height` 与根节点尺寸保持一致。
- 指针捕获在松手、取消、失去捕获、隐藏和销毁时清理；每次物理输入只执行一次动作。
- 键盘动作通过统一 InputRouter 路由，游戏规则由已有动作接口执行。
- 自动化测试使用 Node 和 DOM 替身；实际画面由用户验收。

## 文件

- `dom-ui.ts`、`menu-text.ts`：DOM 层、文字和菜单排版。文字定位同时跟随原点与倍率变化，修改锚点立即更新变换；文字对比底色随样式更新并在复用标签时清除。
- `assets.ts`：图片、图集切片、预加载与资源持有计数。
- `components.ts`：状态栏、轮盘等组件的容器、图片、按钮与指针生命周期。
- `node.ts`：菜单布局树、图片、文本、热区和原生拖动；图片裁边保持原图倍率，翻转只作用于内部图片。
- `surface.ts`：菜单表面、图片等比裁剪与完整显示、通用按钮、九宫格、静态图框、滚动裁剪和键盘聚焦。
- `volume-slider.ts`：音量滑条；轨道高 10、滑块 18×26、热区横向各扩 12，显示与命中共享坐标。
- `action-controls.ts`：轮盘图片、数量、SVG 冷却与多指动作输入。
- 轮盘冷却遮罩直接放在快捷位图标内，和当前图标共用位置与尺寸；切换技能或物品时立即按当前图标更新。
- `status-hud.ts`：主控者、队友和目标的头像、数值槽、状态图标与点击；随场景显隐，数据没变时复用节点与图片。
- `minimap.ts`：合并 SVG 地形与 DOM 标记，图标使用原素材尺寸，标记按身份复用并随地图释放。
- `cooldown.ts`：轮盘与电脑技能行共用的 SVG 冷却扇形、前沿、圆环和秒数。
- `computer-skill-hud.ts`：只读六格技能行，图标、冷却和物品数量共用容器，整行拦截地图点击。
- `move-stick.ts`：摇杆、四向盘、方向轴和按键先后顺序；触摸取消、隐藏或切换模式时回中。
- **HUD 控件区域不把按下事件交给地图。** Phaser 默认还会在 `window` 上处理画布外的 `mousedown`/`touchstart`；`#ui-hud` 层要把这些事件截住，否则点摇杆、按钮或控件之间的空隙会同时命中背后的地图对象。圆形按钮保留自己的圆形热区；技能轮盘另铺一块透明挡板覆盖整组按钮的外接矩形，按钮叠在挡板之上，挡板范围内的空隙由挡板接收。
- 按钮热区用 `top`、`right`、`bottom`、`left` 明确铺满按钮，以兼容安卓旧版 WebView。
- 通用按钮使用完整独立图片和 CSS 图片边框一次绘制，保留两端形状，避免缩放时出现切片接缝；常态和选中态使用相同几何。
- 小地图顶边和主角状态栏的可见顶边对齐界面顶部安全边；状态栏计算时扣除素材顶部透明留白。

## 菜单输入与资源

- 按下和松手都检查当前可见性、可用状态与命中守卫；坐标先换算到节点局部，居中的控件使用中心两侧的热区。
- 隐藏、场景暂停或休眠、取消、失焦和销毁时释放节点及后代的指针捕获与长按。窗口事件继续更新重绘前的指针快照，使长按加点和背包拖放能收到松手。
- 滚动开始后取消内容中所有后代的按下状态，松手不触发按钮；下次按下在捕获阶段重置本次滚动标记。滚轮只作用于收到事件的最上层滚动区。
- 滚动裁剪层与滚动条直接挂在场景坐标层；位置和倍率取所属菜单的完整变换，嵌套菜单只应用一次缩放。
- 静态页签随正文重绘保留，键盘焦点名单同时保留这些活节点；关闭表面时统一释放。
- 局部更新销毁按钮后调用 `UiSurface.pruneDestroyed`，避免键盘焦点名单持有失效按钮。
- 图片通过 `domAssets` 预载与持有，准备状态取 `peek`。`loadUiImages` 将图集文件映射到对应图片并向加载器传递调用方的取消信号。
- 界面图片下载、解码和图集数据各有 15 秒超时，超时释放请求并允许入口重试。
- 场景图片挂在铺满画框的容器，页面按可用空间缩放，独立文字位于同层图片之上；全屏遮挡遵循 `DomUi.setOccluded`。

- `UiSurface.clear(preserve)` 可保留指定子节点。菜单重绘保留正文根节点的 DOM 挂载，使静态层长按按钮不会因为父节点移除而丢失指针捕获。
